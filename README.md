
# MAISON — Fine Dining

A modern, responsive fine-dining restaurant website developed with React and TypeScript.

MAISON is an independent frontend portfolio project that combines editorial-inspired web design, interactive elements, and a refined digital experience.

### Live Website

**[Explore MAISON ↗](https://maison-fine-dining.netlify.app)**

---

## About the Project

MAISON was created as a fictional fine-dining restaurant concept, with the goal of building a visually distinctive and functional website.

The project focuses on combining elegant typography, immersive visuals, responsive layouts, and intuitive navigation.

## Technologies

- React
- TypeScript
- JavaScript
- HTML5
- CSS3
- Vite

## Key Features

- Responsive layouts for desktop, tablet, and mobile
- Custom-designed user interface
- Interactive navigation and visual transitions
- Restaurant presentation and content sections
- Reservation interface
- Reusable React components
- Mobile-friendly user experience

## Development Approach

The project was developed with attention to:

- Component-based frontend architecture
- Visual hierarchy and typography
- Responsive design principles
- Consistent styling and interaction design
- Clear navigation and usability

## Project Type

**Independent portfolio project — fictional restaurant concept.**

Designed and developed as a demonstration of frontend development and web design skills.
